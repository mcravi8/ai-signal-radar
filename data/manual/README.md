# Curated public evidence

This directory is for reviewed public URLs that do not have a free automated collector, including selected LinkedIn posts, X posts, VC essays, podcast transcripts, and job pages.

Manual evidence must contain only:

- a public URL;
- public title, author, organization, and publication date;
- a short original summary;
- candidate themes, projects, and claims;
- source-quality, sponsorship, and commercial-bias labels.

Do not paste full posts, paywalled text, mailbox content, personal contact information, or authentication-bearing URLs.
